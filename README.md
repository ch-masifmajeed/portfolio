# portfolio

Professional portfolio website for Muhammad Asif Majeed - AI Web Developer & Solutions Architect.

## Features

- **Next.js 14** + **Tailwind CSS** - Modern, fast, and responsive
- **6 Projects** showcase with tech stack details
- **AI Chatbot** - Friendly assistant for visitor questions
- **Google Calendar Integration** - Book consultations directly
- **Booking System** - 7 days/week, 9am-10pm availability
- **Meeting Types** - Video call, phone call, in-person
- **Services & Pricing** - Web dev, AI, SaaS, consultation
- **Testimonials** - Client feedback section
- **Blog** - Articles on web dev and AI
- **Free Hosting** - Ready for Vercel deployment

## Pages

- `/` - Home (Hero + Services + Featured Projects)
- `/about` - About Me
- `/projects` - Portfolio (6 projects)
- `/services` - Services & Pricing
- `/contact` - Contact form + AI Chatbot + Booking
- `/blog` - Blog & Articles
- `/testimonials` - Client Feedback
